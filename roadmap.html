PPT Slide 03 • Details in Scope & Python Ideas

Details in Scope

Name Mobile Number Email Address Organization

Python Ideas

  • Input gathers typed information: Standard keyboard / form input.
  • Strings hold text: String operations, stripping, character sanitation.
  • Variables give values names: Distinct bindings for all 5 contact properties.
  • Dictionary / Tuple: Groups related fields into record dictionaries.
  • File Handling: Persistent read ('r') and append ('a') file streams.
PPT Slide 04 • Problem & Objectives
The Problem: Contact details need a clear place to belong. Personal or professional information is harder to use when it is entered without a consistent structure.

Module 1 Objectives

  1. Accept the required contact fields.
  2. Group them into a clear record structure.
  3. Save information using the project's chosen storage method (contacts.txt).
  4. Practice foundational Python and file operations.
PPT Slide 05 & 06 • Planned Module 1 Flowchart

One Path Takes the User from Start to Confirmation

Visual execution pipeline as modeled in the project presentation:

START Run Program / Web App
↓
INPUT Enter Contact Details Name • Mobile Number • Email • Address • Organization
↓
PROCESS Create Contact Record Package fields into pipe-delimited format (name|mobile|...)
↓
I/O Store Contact Information Open contacts.txt in append mode ('a')
↓
FILE WRITE Save Contact Write record string and close file stream
↓
END Display Confirmation Show success alert & render in contacts directory
